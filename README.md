# Blueline Estética Automotiva

Versão estática e editável do site da Blueline Estética Automotiva, preparada para hospedagem no Cloudflare Pages.

## Estrutura
- `index.html` — estrutura da página
- `styles.css` — identidade visual e responsividade
- `script.js` — autoplay do vídeo, controle de som e carrossel
- `assets/` — mídia do projeto

## Publicação no Cloudflare Pages
Configuração recomendada para este projeto estático:
- Framework preset: **None**
- Build command: deixe vazio
- Build output directory: `/`
